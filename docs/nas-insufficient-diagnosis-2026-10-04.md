## 股票清單混有已終止交易的歷史代號

115 檔五項來源全部未通過；173 檔完全沒有評分窗口內的價格日期。其中 170 檔 NAS 根本沒有價格列，另 3 檔價格已停在窗口以前。不能僅憑無資料把全部判成下市，但已查證有歷史股票仍被當成有效普通股：

- 1230 聯成食品：證交所終止上市名單記錄日期 2001-11-01。[官方名單](https://www.twse.com.tw/company/suspendListingCsvAndHtml?lang=zh&startYear=&type=html)

這兩檔最新五項資料下載均回傳 0 筆。`normalize_stock()` 目前只依四位數代號、市場及普通股類型認定 `is_common_stock=True`；`sync_universe()` 只有在代號不再出現在 TaiwanStockInfo 回應時才取消有效狀態，沒有核對當前交易所有效名單或終止交易日期。只要資料商保留歷史代號，它就持續進入補抓與資料不足統計。這是仍需修正的名單處理問題，不能期待重抓近期資料就消失。

## 日期齊全但數值無法使用

價格不足的 226 檔中，195 檔缺交易日期，另 31 檔日期齊全，但起算日 2026-09-02 的收盤價為 0，`PriceReturn20D` 無法計算。31 檔全部已在 price_daily 核對起算日為 0。

例如 1538 正峰原始 Parquet 回應直接記錄 9/2 `close=0`、成交股數 110、成交金額 935；不是這次資料庫查詢遺失價格。必須核對無成交／零股與價格來源的語意後，才能決定有效替代價格，不能直接把 0 當正常收盤價或任意前值填補。

另有歷史長度不足的例子：3718 中光電投控在 NAS 最早價格日期是 9/3，其他四項來源已齊，仍缺 21 日價格窗口的 9/2。這是現有來源窗口不足，不能只因其他來源完成就產生數值評分；本次沒有額外查證其上市日期。

## 介面原因統計仍有舊資料問題

`_display_score_metrics()` 的目前可評分／資料不足數量來自目前股票結果，但 `missing_reason_counts` 直接取最後一個全市場 score job 的快照，因此 API 仍回傳昨天的法人不足 1,808、外資持股不足 1,834 等數字，並不是目前 517 檔的分布。本報告的 514／263／226／176／116 已直接從逐股最新評估重算。

## 後續處理重點

1. 用交易所有效股票名單與生效日期管理 universe，保留歷史資料，但不再要求已終止交易代號取得當前窗口資料；對轉板／更換代號需處理生效日期，不能以任何歷史下市紀錄直接刪除。
2. 對當前仍交易股票，區分供應商未提供、無法人交易、暫停交易、上市歷史不足與真正漏抓；取得權威來源語意後再決定是否允許零值或補用其他來源。
3. 額外呈現價格為零／歷史不足等原因，並把 API 的缺失原因彙總改成與目前逐股結果一致。
